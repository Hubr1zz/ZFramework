# 项目玩法实现：战斗机制索引

本页记录当前工程**已经实现**的战斗机制。判定“正式玩法”的依据是：机制由 `PlayableBootstrapSettings` 配置、进入 `BossFight` 后由 `PlayableCombatSession` 调用；仅有规则类、测试场景或旧兼容代码不算正式接入。下列链接指向仓库中现存的详细设计页；设计页与现行实现不一致时，以当前代码和内容资产为准。

## 正式决战流程

- **进入与结束战斗**：遭遇建立独立决战会话和出战名册；Boss 全局生命归零后结算胜利与掉落，使用第一武器造成过有效伤害的幸存猎人获得该武器熟练度；小队全灭则按失败返回战役流程。设计详情：[决战阶段编排](../openspec/specs/showdown-phase-orchestration/spec.md)、[Boss 部位卡规则](../openspec/changes/design-import-20260724-boss-hit-locations/specs/boss-hit-locations-rules/spec.md)。全局生命和武器熟练度收益是现行实现补充，链接的设计页尚未描述。
- **回合、前摇、后摇与时点**：预告的 Boss 卡给出本轮时点上限；猎人先行动，Boss 随后执行，结果确认后揭示下一轮。行动超额仍生效，但会提前结束该猎人本轮行动并结转压力；超时者可由队友用“鼓舞”援助。设计详情：[战斗回合与时点规则](../openspec/changes/design-import-20260724-combat-turn-timeline/specs/combat-turn-timeline-rules/spec.md)。前摇、后摇的界面引导属于现行实现补充。
- **猎人行动卡**：当前共享内容为“谨慎推进、武器攻击、专注、鼓舞”；费用在选择与校验后提交，卡牌可按配置翻面、恢复或爆发。设计详情：[猎人行动卡规则](../openspec/changes/design-import-20260724-hunter-action-cards/specs/hunter-action-cards-rules/spec.md)。
- **思维区与战斗灵感**：每名猎人有容量有限的思维区；红、蓝、黄灵感可支付卡费，满容量时选择替换或放弃。Boss 的锁定负面卡占容量，但不能当灵感消费。设计详情：[猎人行动卡实现设计](../openspec/changes/design-import-20260724-hunter-action-cards/design.md)；容量和负面占位尚无独立设计页。
- **猎人移动与武器攻击**：移动选择有效空格；攻击前从携带武器中选射程合法的一把，武器影响攻击力与尝试次数。每次攻击抽结果牌、选择受击部位并逐个结算。设计详情：[猎人行动卡规则](../openspec/changes/design-import-20260724-hunter-action-cards/specs/hunter-action-cards-rules/spec.md)、[Boss 部位卡规则](../openspec/changes/design-import-20260724-boss-hit-locations/specs/boss-hit-locations-rules/spec.md)。
- **Boss 部位卡**：部位有抽取权重、韧性、独立耐久与效果；玩家决定多部位结算顺序。部分卡会因前一次成功而提高韧性；持续部位翻开后留场，可在后续攻击中直接选择，摧毁后不再抽取。有效命中同时削减 Boss 全局生命。设计详情：[Boss 部位卡规则](../openspec/changes/design-import-20260724-boss-hit-locations/specs/boss-hit-locations-rules/spec.md)；堆叠与持续部位为现行实现扩展，尚无独立设计页。
- **Boss 行动、移动与索敌**：当前“黑暗撕咬”按最近存活猎人确定规则目标，移动一格后按射程攻击。玩家可选择落点与实际目标；偏移会增加相应猎人的命运值，目标超出射程则按卡牌失败文本落空。设计详情：[Boss 行动牌堆与目标选择规则](../openspec/changes/design-import-20260724-boss-action-deck-targeting/specs/boss-action-deck-targeting-rules/spec.md)；操控偏移与命运增量尚无独立设计页。
- **Boss 命中与猎人伤势**：每次攻击按怪物精准和猎人闪避组成命中牌堆；命中后先算部位护甲，再扣头、躯干、手臂或腿的生命。设计详情：[Boss 攻击结算规则草案](../openspec/drafts/changes/design-import-20260724-boss-attack-resolution/specs/boss-attack-resolution-rules/spec.md)、[猎人伤势与死亡规则](../openspec/changes/design-import-20260724-hunter-injury-death/specs/hunter-injury-death-rules/spec.md)。
- **致命伤、存活事件与生存卡**：生命已归零的部位再次受到有效伤害时，从可见构成、背面相同的死亡牌堆抽一张；死亡牌使猎人阵亡，普通存活牌触发事件池，特质授予的生存卡对应指定事件。存活后增加一张死亡牌，并可留下永久损伤；伤亡同步回营地。设计详情：[猎人伤势与死亡规则](../openspec/changes/design-import-20260724-hunter-injury-death/specs/hunter-injury-death-rules/spec.md)；事件池与生存卡是现行实现扩展，尚无独立设计页。

## 已有规则，但未接入当前正式战斗内容

- **战场地形与击退**：领域层已有可重叠/可破坏地形、草丛闪避、石块“投石”和击退碰撞规则；当前正式配置未绑定战场规则资产，决战会话也未调用这些地形/击退服务，因此不应把它们当作玩家现时可用的动作。设计详情：[战场交互规则](../openspec/changes/design-import-20260724-battlefield-interactions/specs/battlefield-interactions-rules/spec.md)。

`3DCardTest` 和 `UnitTests` 是试验或验证入口；`LegacyShowdown` 目录则仍包含正式会话复用的数据与装配代码，不能仅凭目录名判断其玩法是否废弃。原始设计源文件未随当前仓库入库；本页链接的是可在工程内打开的 OpenSpec 设计页。
