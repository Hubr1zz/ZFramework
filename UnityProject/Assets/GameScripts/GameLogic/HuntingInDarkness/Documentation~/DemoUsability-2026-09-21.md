# Demo Usability 2026-09-21

本记录限定在表现层输入、相机和 UI，基线为本次修改前的未提交工作区。

改动包括：

- 取景改为按包围盒八角计算透视距离，覆盖 16:9、4:3、平扁宽桌和有高度内容。
- 相同活动 `Request` 不再重复触发取景刷新，避免玩家平移或缩放被复位；边界更新仍会刷新。
- 营地和狩猎使用中键平移、WASD/方向键、Home 复位和滚轮缩放；狩猎右键留给卡牌，贴边平移默认关闭，并限制在相机像素区域、聚焦且无拖拽时生效。
- 三个相机共用场景持久化的中文操作提示；长文详情使用独立屏幕 UI，不改物理表现；运行时不重建 UI。

维护位置是 main 场景中的三个相机组件和 `Assets/AssetRaw/UI/Prefabs/TabletopUsability.prefab`。一次性 installer 运行后删除。

操作说明：营地/狩猎支持中键平移、WASD/方向键、Home 和滚轮；Boss 支持中键旋转、WASD、滚轮，Home 只复位全景。悬停卡牌按 F 查看详情，详情中按 F、Esc 或右键关闭；H 或操作按钮显示提示。

测试结果：Unity 6000.5.9f1 EditMode 13/13；PlayMode 首轮 39/42，定向复验 10/10，按 fullname 合并后 42 个用例全部通过。覆盖透视取景、卡桌布局、详情滚动与防穿透、卡牌实例化、狩猎探索移动采集返营、跨季跨年再出征、工坊制作与消耗品使用、暂停时入场镜头。结果 XML 位于仓库根 `.agent-memory/usability-20260921/{edit-results.xml,play-results.xml,play-recheck-results.xml}`。

验证边界：基于任务开始时未提交工作区的备份核对；Core、GameCore、生产 Adapters、所有原 `.meta` 和玩家存档均未变，main 场景只新增持久化表现组件与 Prefab 引用。一次性 installer 已删除。详情 UI 已通过离屏渲染检查（`details-preview.png`）；长文回顶与滚动条同步的下一帧断言复验 1/1 通过（`ui-final-results.xml`），最终离屏截图已核对。系统锁屏导致无法执行人工完整试玩，这不等同于人工体验验收。

未改问题与后续方案：现有世界空间卡桌仍大量在运行时通过 `Create`/`MakeText` 构建，后续可专门资产化其布局并显式引用。本次不做全盘迁移，也未发现本次修复必须改玩法。若进一步做战斗失败原因预览，先确定只读查询接口并复用权威校验，不在 UI 复制规则；该建议本次未实现。
