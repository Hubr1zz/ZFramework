# 可拆分工作流包

完整工作流按三层组合：

| 层 | 包 | 可独立工作 | 职责 |
| --- | --- | --- | --- |
| 文档维护层 | `document-workflow/` | 是 | 设计文档、知识库、术语、灵感、案例、历史和实现后变更账本 |
| 项目层 | `zWorkFlow/` 根包 | 是 | 项目事实、OpenSpec、实现、重构、团队和 Unity 工作台 |
| 中间层 | `document-project-bridge/` | 可选 | 项目侧只读检查“已实现后又修改”的设计文档，辅助用户决定是否重新设计导入 |

文档包和项目包互不依赖。文档包独立维护 `.design-workflow/implementation-ledger.json`，其中不保存项目绝对路径；中间层只有找到该关键文件才建立项目侧本机桥接，并只读展示文档结构、实现进度和实现后变更，不自动调用项目工作流，也不把项目架构规则写回文档包。
