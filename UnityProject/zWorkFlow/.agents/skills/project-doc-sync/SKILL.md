# Project Doc Sync

对当前代码改动做文档对齐，修正项目文档中过时、缺失或冲突的内容。

## 默认文档位置

按顺序查找：

1. 用户指定的文档或模块权威说明
2. `zWorkFlow/`（仅工作流文档）或 `.agents/project-docs/`
3. `docs/`、`README.md`
4. OpenSpec / ADR

工具专属薄入口只在其路由本身变化时更新，不承载完整项目文档。

## 执行流程

1. 确定同步范围：优先使用用户给出的模块或子系统；没有参数时，根据最近代码改动和 `git diff` 判断。
2. 核验代码事实：读取相关代码，必要时用 `rg` 搜索实际 API、类名、事件、资源路径。
3. 扫描现有文档并比对。
4. 以当前代码为准更新直接相关文档。
5. 更新索引或交叉链接。
6. 输出同步报告。

## 输出格式

```text
文档同步完成。
- 核验范围：
- 更新文档：
- 关键对齐点：
- 未处理风险：
```
