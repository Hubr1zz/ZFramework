# Project Context

本 skill 是项目内容层，不是可直接复用的架构设计层。迁移到新项目时，用新项目自己的领域、目录和系统状态替换 references。

## 必读入口

- [PROJECT-INDEX.md](references/PROJECT-INDEX.md)

## 使用规则

先按索引跳到任务命中的参考和代码，不得默认读取其余 references。若文档与当前代码冲突，以代码为准，并用 `workflow-reflection` 记录差异。
