# Boss 行动牌堆与目标选择设计导入

## 模块边界

- 权威 owner：BossActionDeck 与 TargetSelectionPolicy
- 职责：独立管理 Boss 行动牌堆、攻击/非攻击行动、目标类型和锁定策略。
- 独立性：本模块具有独立状态/生命周期和验收场景，可单独实现与测试。

## 目标

交付“Boss 行动牌堆与目标选择规则”与对应实现 Feature，并通过显式依赖与其他战斗模块协作。

## 范围外

不复制其他战斗模块的内部规则；跨模块交互只通过依赖契约表达。

## 验收

- 规则 Scenario 可由本模块接口独立验证。
- 实现差异全部映射为任务。
- Unity 表现不成为规则权威状态。
