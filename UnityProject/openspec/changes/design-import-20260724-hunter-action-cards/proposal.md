# 猎人行动卡设计导入

## 模块边界

- 权威 owner：行动卡运行时模块（CharacterActionCardInstance、费用结算器与 Action Queue 执行服务）
- 职责：独立管理行动卡费用、双面状态、恢复、爆发和动态结算流程；基础行动卡沿用普通行动卡定义，意志行动沿用同一行动卡管线。
- 独立性：本模块具有独立状态/生命周期和验收场景，可单独实现与测试。

## 目标

交付“猎人行动卡规则”与对应实现 Feature，并通过显式依赖与其他战斗模块协作。费用定义 SHALL 与卡牌效果解耦，首批覆盖时点、战斗灵感和需要玩家输入的特殊费用；结算流程 SHALL 通过可暂停、恢复和动态插入步骤的 Action Queue 保证顺序。

## 范围外

不复制其他战斗模块的内部规则；跨模块交互只通过依赖契约表达。不在本 Change 中猜测“转向”“硬撑”等具体卡牌效果，也不把 Action Queue 提升为新的独立 Architecture capability；当第二个能力需要直接复用该契约时再执行提取。

## 验收

- 规则 Scenario 可由本模块接口独立验证。
- 混合费用、等待玩家输入、取消与动态追加步骤的结算顺序可由确定性测试验证。
- 基础行动卡由猎人初始卡配置提供，意志行动使用普通行动卡管线并具有每回合重置的可用状态。
- 实现差异全部映射为任务。
- Unity 表现不成为规则权威状态。
