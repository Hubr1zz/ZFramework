# 猎人攻击结算规则

## ADDED Requirements

### Requirement: 猎人先选择武器和合法目标
猎人攻击 SHALL 先选择可用武器并通过范围与目标合法性校验；武器速度决定一次攻击生成的命中次数。

#### Scenario: 目标不合法
- **WHEN** Boss 不在所选武器的合法范围内
- **THEN** 攻击不开始且不消耗本次攻击结算资源

### Requirement: 猎人攻击使用临时结果牌堆
每次攻击 SHALL 以猎人力量、武器威力和 Boss 韧性构建临时成功/失败牌堆；力量至少生成 1 张成功卡，武器威力忽略等量韧性，剩余韧性生成失败卡。

#### Scenario: 抽取命中结果
- **WHEN** 临时牌堆完成混洗
- **THEN** 系统按武器速度抽取攻击结果

#### Scenario: 分配攻击结果
- **WHEN** 命中结果与部位均已展示
- **THEN** 玩家把结果分配到部位并选择结算顺序

#### Scenario: 攻击结束
- **WHEN** 所有已分配结果和部位效果结算完毕
- **THEN** 系统销毁本次临时牌堆并发出攻击完成结果
