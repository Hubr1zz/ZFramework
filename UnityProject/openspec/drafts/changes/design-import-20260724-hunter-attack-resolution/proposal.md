# 猎人攻击结算设计导入

## 模块边界

- 权威 owner：HunterAttackResolver 与临时攻击结果牌堆
- 职责：独立处理武器/范围校验、命中数量、成功失败牌堆、结果抽取、部位分配与攻击完成。
- 独立性：本模块具有独立状态/生命周期和验收场景，可单独实现与测试。

## 目标

交付“猎人攻击结算规则”与对应实现 Feature，并通过显式依赖与其他战斗模块协作。

## 范围外

不复制其他战斗模块的内部规则；跨模块交互只通过依赖契约表达。

## 验收

- 规则 Scenario 可由本模块接口独立验证。
- 实现差异全部映射为任务。
- Unity 表现不成为规则权威状态。
